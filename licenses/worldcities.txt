The application's versioned JSON city catalogue was converted from the
complete user-supplied Basic CSV. Conversion preserved every unique source
identity and city value, including Unicode/ASCII names, country spellings,
capital metadata, coordinates and nullable population; duplicate city names
are retained. The JSON is now the hand-maintained search source of truth.
The PostgreSQL catalogue is synchronized explicitly from JSON and adds stable
application UUIDs and spatial indexing. Retire entries rather than deleting
them. Catalogue changes are not endorsed by Simplemaps.

Validate catalogue edits with `npm run cities:validate`; use
`npm run db:import:cities -- [--dry-run]` to synchronize the database.
The API loads the packaged JSON at startup, so catalogue edits require a
release/restart. Public pages credit Simplemaps and link to the source and licence.
This attribution concerns the city dataset, not the application's code.
